# G4 Codec Landing Protocol

**Date:** 2026-08-15  
**Status:** pre-registered before the instrument exists  
**Amendment protocol:** identical to `docs/gates.md` — any change is a recorded amendment executed before re-running, never tune-and-rerun.

---

## 1. Subject

Each configured model, on this daemon's own serving path (the same `Pager::infer` `/v1` uses), on the declared tier.

## 2. Instrument

Fixture set `codec-tasks-v1` — N=20 single-defect repair tasks (10 `python` lens, 10 `plaintext` lens), each with a verified reference landing, embedded in the daemon binary. Run through the real `run_task` (P3), envelope lens name `bloomery-task-envelope-v1`.

Per fixture: fresh scratch dir, fresh ephemeral agent (default priority, `window_cap = None`, budget 30,000 tokens — *chosen+sanity:* backstop ≈ 6 steps × (prompt ≲4k + completion 1024); steps are the real bound), `max_steps = 6` (*chosen+sanity:* 2× the expected read→patch→done path), grants = read+write on the fixture dir only, **no commands**, `network: false`, patch codec = the model's profile-selected codec (rule 4), `mutating_verbs = true`.

## 3. Scoring Rule (Per Fixture)

The fixture **lands** iff BOTH (a) the task produced at least one `patch` step with `failed == false`, AND (b) the declared target file's final bytes differ from its initial bytes.

Recorded edges, accepted:
- An identity patch (applies, changes nothing) scores NOT landed — a repair fixture's reference always changes bytes, so a byte-identical result is a non-repair.
- A patch landed only on some other/new file scores NOT landed — the gate licenses real edits, not scratch-file creation.
- Terminal `Done`/`StepsExhausted`/`BudgetExhausted` are all scored.
- `TaskStatus::Error` (or agent-creation refusal) is an **infrastructure abort** — the model's whole probe stops, no verdict is recorded, the model is *unmeasured* (fail-closed read-only), and the abort reason is journaled `Degraded`.

Never splice a partial score.

## 4. Codec Selection Rule

From the attached assay profile's `codecs` grid at grade `"small"` (assay's `_GRADE_FOR_VERDICTS`), comparing `lands_applies`:
- Whole_file strictly greater → `WholeFile`
- Otherwise `SearchReplace` when it is measured
- Only one measured → that one
- Neither measured or no profile → default `SearchReplace` (the robigo-proven default), and the verdict's `detail` says `"default (codecs unmeasured)"`

## 5. Decision Rule

Integer form `landed * 5 >= n * 4` (exactly "landing ≥80%", no float edge) → mutating verbs kept; else demoted to read/find/done.

**The point estimate decides.** Wilson 95% interval recorded with every verdict; `provisional = (lo < 0.80 && 0.80 < hi)` — provisional marks the record, it never changes the decision.

*Derived sanity (via assay's `wilson95`, the reference implementation):*
- 20/20 → lo 0.8389 (a decided keep is possible)
- 12/20 → hi 0.7812 (a decided demote is possible)
- 16/20 → (0.5840, 0.9193) straddles → provisional keep

N=20 can decide both directions; that is the sample-size justification.

## 6. Enforcement

Demoted/unmeasured models get a read-only verb card AND a structural dispatch refusal (prompting alone is not enforcement). Demotion is per-boot state (the gate runs at admission; restart re-measures), journaled (`CodecVerdict` / `Degraded`) and surfaced in `/status`.

## 7. Honest Outcomes

Every local 7B demoted is a valid, pre-registered outcome, not a failure; the black-oxide fine-tune flywheel is the recorded escalation. The gate measures codec landing under the OS envelope — NOT task/repair success.

## 8. Amendment Protocol

Identical to `docs/gates.md` — any change is a recorded amendment executed before re-running, never tune-and-rerun.

## 9. Amendment 1 — window exhaustion is scored (2026-08-15, Brice-approved, recorded BEFORE any re-run)

**Motivating observation (qwen3:14b rung-1 attempt, 2026-08-15):** mid-fixture,
the substrate refused honestly — verbatim: `refusing: 24533 cached + 593
prompt + 1024 requested tokens exceed the window of 25600 tokens` — because
the model's thinking-verbosity filled the fixture agent's KV window. The task
loop mapped the refusal to `TaskStatus::Error`, which §3 classified as an
infrastructure abort, leaving the model unmeasured. At the abort, one fixture
had scored and no verdict existed — no measurement was consumed by this
amendment.

**Amendment to §3:** a mid-task window exhaustion (`PagerError::
PromptTooLarge` returned by `infer` during a fixture run) is a **scored**
outcome, not an infrastructure abort — the model exhausted an
envelope-bounded resource (its measured context window) without landing,
exactly the `BudgetExhausted` shape §3 already scores. The task loop maps it
to a new terminal `TaskStatus::WindowExhausted`; the probe scores that
terminal by the unchanged §3 conjunction (in practice: not landed unless a
patch already landed earlier in the task). `TaskStatus::Error` (substrate
faults, journal failures, agent-creation refusals) remains an infrastructure
abort. No other §3 rule, no §5 number, and no instrument parameter changes.

## 10. Amendment 2 — envelope-v2, the think-preseeded lens (2026-08-16, Brice-approved, recorded BEFORE the instrument change)

**Motivating observations:** three rungs under envelope-v1 (qwen2.5-coder-7B
0/20, qwen3:14b 1/20, qwen3.8-27b-Q3 0/20 all-WindowExhausted with zero
patch actions) show that for thinking models the binding constraint is
`<think>` verbosity against the per-turn cap and the window, upstream of
codec ability. A recorded feasibility probe (2026-08-15 eve, Q3 subject)
showed `/no_think` does NOT suppress thinking under the raw-completion
lens, while appending a pre-closed think block to the prompt does.

**Amendment: a SECOND envelope lens, `bloomery-task-envelope-v2`,** equal
to envelope-v1 in every respect except that the rendered task prompt ends
with the literal pre-seed `<think>\n\n</think>\n\n`, so the model
continues from an already-closed think block. Rules:

- Envelope selection is an explicit operator config (per-model
  `think_preseed = true` in the models table; absent = false =
  envelope-v1). Nothing selects it automatically.
- **The lens name travels:** every `CodecVerdict` (and the fixture rows'
  interpretation) records which envelope produced it. v2 results are
  their own rungs — NEVER comparable to or averaged with v1 rungs of the
  same model (assay's measured lesson: landing is model × codec ×
  presentation).
- No other rule changes: same fixture set, same scoring conjunction
  (§3 + Amendment 1), same decision rule (§5), same parameters (§2),
  same greedy sampler, same no-chat-template prompt path.
- The gate's enforcement consequence attaches to the (model, envelope)
  the operator actually configures for tasks: a model demoted under v1
  but passing under v2 earns mutating verbs only when the daemon is
  configured with `think_preseed = true` for it — the verdict stored in
  the pager is whichever lens the boot's probe ran.
- Honest possibility, pre-registered: v2 may LOWER landing (Qwen3's
  no-think mode trades capability); measuring that is the point.
